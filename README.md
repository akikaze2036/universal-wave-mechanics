## この理論について

`4次元不変母体宇宙論` は、宇宙を「波」として捉えることから始まった。  
その発想を検証と議論によって磨き上げ、宇宙の舞台である「母体」から「万有（すべてのものに働く波と作用）」へと射程を広げて一つの体系にまとめたのが本論である。

万有の正体はエネルギー密度の濃淡であり、波として振る舞う。  
素粒子や力はもちろん、原子、生物、地球、太陽系、銀河、そして宇宙そのものまで――すべてが同じ波の現れだ。  
**いまこの文章を読んでいる「人間」という存在もまた、エネルギー密度の濃淡である素粒子の集まりにほかならない。**

無数の宇宙論が生まれる中で、このモデルはどこまで現象を貫けるのか。その答えを、本論と外伝で確かめてほしい。

<br>

## 3行でわかる『万有波動力学』

* **すべてのもの（万有）は波である**：正体は4次元不変空間におけるエネルギー密度 $u(x, y, z, \tau)$ の濃淡と、密度・質量に伴う作用。
* **母体と万有は同じルールで動く**：宇宙が生まれ衰退する舞台（母体）も、その中の物質や生命（万有）も、単一の基礎方程式に従う。
* **宇宙は「影響範囲」として重なり合う**：閉じた箱ではなく開かれた波の広がりとして生滅を繰り返し、互いに干渉し合っている。

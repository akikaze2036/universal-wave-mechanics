## 万有波動力学 【予言・概念モデル】
**旧 4次元不変母体宇宙論** <br>
<br>
4次元不変母体宇宙論は波で宇宙を説明した。<br>
その宇宙論を検証や議論を深めて行き、本論にまとめた。<br>
本論は宇宙を含むすべて（万有）を統一したシンプルな法則で説明する。<br>
<br>
万有の正体はエネルギー密度の濃淡であり波の振る舞いをしている。<br>
万有とは素粒子や力だけでなく、原子、生物、地球、太陽系、銀河、宇宙などすべてである。<br>
人間と言う存在もエネルギー密度の濃淡である素粒子の集まりなのだ。<br>
<br>
### 構成と案内
* **本論（`PAPER.md`）**：母体と万有の同一性、基礎方程式が伝える波の力関係、そして宇宙の誕生と干渉の仕組みをまとめた理論の核となる文書です。
* **外伝『万有波動力学からわかる宇宙』**：本論の枠組みから導かれる宇宙の多様性と寿命、物質生成と波紋の運搬、相対速度による現象、さらにブラックホール・光速の壁・ダークマター不要論といった未解決問題への視点を掘り下げます。
* **検証に向けて**：本理論は完成された教義ではなく、現実の観測や思考実験と突き合わせながら検証・議論を深めていくためのモデルです。
